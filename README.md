# LiAu · Honey & Brand Identity

Интерактивная 3D WebGL-сцена жидкого мёда с оптической дисперсией стеклянного логотипа **LiAu** и презентацией айдентики бренда.

## Особенности

- **WebGL-шейдеры**: двухпроходный рендеринг высот текучей медовой материи и реалистичного преломления света (Soft Prism Glass).
- **Hero-секция**: занимает весь вьюпорт (100vw × 100vh).
- **Скрытое меню настроек**: вызывается и скрывается по нажатию клавиши **`H`** (или **`Р`** в русской раскладке). Позволяет настраивать сорт мёда (акациевый, липовый, цветочный, гречишный, каштановый), рельеф, вязкость, преломление, дисперсию и параметры логотипа.
- **Секция бренда**: при скролле вниз открывается блок с оригинальным векторным логотипом [`LiAu-01.svg`](LiAu-01.svg) и подробным описанием концепции знака и типографики.

## Управление

- `Движение мыши / Тач`: интерактивные волны и динамические блики на поверхности мёда.
- `H` / `Р`: показать / скрыть панель параметров.
- `Drag & Drop`: перетаскивание любого SVG/PNG логотипа прямо на сцену.
